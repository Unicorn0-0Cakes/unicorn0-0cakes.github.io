Games

Games are their own discipline here, not a subfolder of software. A game is a systems problem, an interaction problem, an art-direction problem and a psychology problem arriving at once, and the only way to judge one is against all four.

This wing is built. It is not yet full.

There is one entry below, and it is a design document rather than a game — the systems are specified and the alpha scope is defined, but nothing has been implemented. Presenting it as a release would be exactly the kind of thing the rest of this site is arranged to avoid.

This wing is intentionally sparse. It is a first-class discipline here because it is a deliberate part of where the work is going, not because there is a shelf to fill. Playable work will appear as it is finished, and not before.
