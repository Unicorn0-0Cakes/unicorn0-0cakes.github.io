A note on the numbers

Three of these projects are Jupyter notebooks whose cell outputs were cleared before they were committed. That means most stored metrics are simply gone. Rather than reconstruct plausible figures, this section reports only what can be traced to the notebooks themselves — which is a complete set for the emotion detector, a single author-reported figure for SVHN, and nothing at all for the turbofan model.

It makes the section look thinner than it is. It also means every number on it is real.

02 How these are evaluated

The same four questions, asked of every model here.

What is it scoring against?

A held-out split, and how it was made. An accuracy figure without its baseline is decoration.

What is the class balance?

The emotion detector's surprise class is around 21% of the data. That number belongs next to the accuracy, not in a footnote.

What did it cost?

The deepest SVHN network was abandoned — not because it scored badly, but because it needed restarts for memory and made hyperparameter search impractical.

What would break it?

Every project page ends with limitations, and they are specific ones.
